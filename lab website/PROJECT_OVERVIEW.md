# 🧬 Project Overview: Herbal Omics Lab

## 🔬 Website Name
**Herbal Omics Lab (Digital Headquarters)**

## 🎯 Purpose
To provide a world-class, dynamic, and interactive platform for the **Herbal Omics Laboratory**. The site serves as both a public-facing informational portal and a private, secure Management System (CMS) for the Principal Investigator (PI) to control laboratory sessions, research data, and team profiles without requiring technical knowledge.

## 👥 Target Audience
1.  **Internal Researchers & Students**: For tracking lab sessions, meeting history, and goals.
2.  **Prospective Collaborators**: To explore the lab's facilities, research impact, and PI profile.
3.  **Academic Community**: To view latest publications and ongoing research trajectories.
4.  **Applicants**: To apply for PhD or Intern positions directly through the portal.

## 🚀 Core Features
- **Flat-File JSON CMS**: A high-efficiency data management system that avoids the overhead of traditional databases.
- **Real-Time Live Sync**: Near zero-latency synchronization between the Admin Dashboard and the public site.
- **Secure PI Dashboard**: A password-protected suite for full laboratory data control.
- **Dynamic Session Scheduler**: Interactive meeting history and presenter tracking with automatic countdowns.
- **Adaptive UI**: A premium, high-contrast Dark/Light mode interface with focus on scientific data visualization.
- **Automated Applications**: A centralized form and file upload system for potential lab members.

## 🛠️ Tech Stack Preference
- **Core Framework**: Next.js 16 (App Router) for hybrid rendering and internal API routes.
- **Frontend Logic**: React 19 (Hooks, Context, Client Components).
- **Styling**: Tailwind CSS & Vanilla CSS Modules for granular control.
- **Animations**: Framer Motion for scroll-triggered entrance and staggered UI interaction.
- **Icons**: Lucide React for consistent vector-based scientific iconography.
- **Persistence**: File System (fs) based JSON interaction (Local-first architecture).
