# 🤝 Contributing to Herbal Omics Lab

Welcome! We are excited that you want to contribute to the Herbal Omics Lab project. Whether you are fixing bugs, adding features, or improving documentation, your help is appreciated.

## 🚀 How to Contribute

1.  **Fork the Repository**: Click the 'Fork' button at the top of the repository page.
2.  **Clone Your Fork**:
    ```bash
    git clone https://github.com/YOUR_USERNAME/Herbalomicslabcommunity.git
    ```
3.  **Create a Feature Branch**:
    ```bash
    git checkout -b feature/amazing-new-feature
    ```
4.  **Commit Your Changes**:
    ```bash
    git commit -m "feat: add some amazing feature"
    ```
5.  **Push to Your Fork**:
    ```bash
    git push origin feature/amazing-new-feature
    ```
6.  **Open a Pull Request**: Go to the original repository and click "New Pull Request."

## 📜 Guidelines
- Follow the existing code style (Next.js App Router patterns).
- Ensure all new features are documented in the `docs/` directory.
- Respect the **Code of Conduct**.
