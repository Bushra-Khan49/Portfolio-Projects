TOPIC 12

EVOLUTIONARY LOGIC

From Molecular Damage to Variant Calling

Damage vs Mutation

This distinction is fundamental.

Chemical damage

\( C \rightarrow U \)

This is a lesion. The original genomic information has not necessarily been permanently changed yet. If repaired, no mutation remains.

But if replication converts the lesion into a stable base-pair change:

\( C:G \rightarrow T:A \)

then we have a mutation.

\( \boxed{ \text{damage} \neq \text{mutation} } \)

Mutation can be the heritable consequence of unrepaired damage.

The Epigenetic Trap: 5-Methylcytosine

There is an especially important complication. DNA can contain 5-methylcytosine, which is cytosine with a methyl group at C5.

If it undergoes deamination:

\( \boxed{5mC \rightarrow T} \)

The resulting base T is a normal DNA base. Therefore, it creates a mismatch that is more difficult to distinguish from an ordinary T.

Notice the conceptual symmetry:

  • Unmethylated cytosine: C → U. U is abnormal in DNA.
  • Methylated cytosine: 5mC → T. T is normal in DNA.
\( \boxed{ 5mC\text{ deamination can evade the simple “U is abnormal” strategy} } \)

This is a major bridge between epigenetics, DNA damage, and mutation spectra.

Transitions vs Transversions

There are two classes of nucleotide substitutions.

Transitions
Purine → purine: \( A \leftrightarrow G \)
or pyrimidine → pyrimidine: \( C \leftrightarrow T \)

Transversions
Purine ↔ pyrimidine: \( A/G \leftrightarrow C/T \)

\( \boxed{C\rightarrow T = \text{transition}} \)

The Physical Repair

A uracil-DNA glycosylase can hydrolyze the N-glycosidic bond connecting the base to the deoxyribose. Conceptually:

\( DNA-U \xrightarrow{\text{glycosylase}} DNA\text{-abasic site} \)

The base is removed, but the sugar-phosphate backbone initially remains. So:

\( \boxed{ \text{base removed} \neq \text{strand removed} } \)

The DNA now contains an AP site (apurinic/apyrimidinic site). An AP site is chemically unstable and is processed by downstream repair machinery:

AP site ↓ phosphodiester backbone cleavage ↓ gap ↓ DNA synthesis ↓ ligation

The Computational Abstraction

Sequencing Does Not See "C"

This is an important conceptual correction. A FASTQ file contains ACGTACCGT...

But the sequencer did not directly see a letter C. It measured some physical signal. Depending on the technology, that might involve:

  • fluorescence
  • electrical current
  • ionic changes
  • polymerase kinetics

The computational system transforms:

\( \boxed{\text{physical signal}} \rightarrow \boxed{\text{base call}} \)

So even the letter "C" is already a computational abstraction.

Three Levels of the Same Event

Level 1 — Molecular
\( C:G \rightarrow U:G \)
chemical damage.

Level 2 — Genetic
After replication: \( C:G \rightarrow T:A \)
stable sequence change.

Level 3 — Computational
The reference genome contains: ...C...
while the sample contains evidence for: ...T...

A variant caller may therefore produce: REF=C, ALT=T.

The VCF does not know that the molecular mechanism was cytosine deamination. It is reporting an observed/inferred sequence difference.

\( \boxed{ \text{VCF representation} \neq \text{molecular mechanism} } \)

What Does a Variant Caller Do?

Suppose the reference has A C G T A. At one position, reads contain:

Read 1: A C G T A Read 2: A C G T A Read 3: A T G T A Read 4: A T G T A Read 5: A T G T A

Imagine \( n=100 \) reads cover a position, with 80 = C, 20 = T. A naive allele fraction is:

\( \boxed{AF=20\%} \)

But the caller cannot simply say "20% T means mutation." It must consider sequencing errors. If the per-base error probability is \( \epsilon = 0.001 \), then \( P(T|C)=0.001 \).

A real variant should generate substantially more T observations than expected from random sequencing error.

Bayesian View of Variant Calling

Conceptually, the caller wants \( P(\text{variant}\mid\text{reads}) \). Using Bayes’ theorem:

\( \boxed{ P(V|D) = \frac{P(D|V)P(V)}{P(D)} } \)

where \( V \) = variant hypothesis, \( D \) = sequencing data.

The key term is \( P(D|V) \) — How likely are the observed bases if a true variant exists?

Compare this with \( P(D|\neg V) \) — How likely are the same observations if no variant exists? Therefore:

\( \boxed{ \frac{P(D|V)}{P(D|\neg V)} } \)

is essentially asking: How much more strongly do these reads support a variant than sequencing noise?

Mutation Spectra & Context

Why Sequence Context Matters

Suppose we simply record: \( C\rightarrow T \). We have discarded information.

Instead, record: 5'-A[C>T]G-3'

Now the mutation has a local context. For trinucleotide-based mutation classification, one often represents substitutions using the six pyrimidine-centered classes:

\( C>A,\ C>G,\ C>T,\ T>A,\ T>C,\ T>G \)

with reverse-complement normalization allowing all substitutions to be represented consistently.

The computational system can therefore transform:

\( \boxed{\text{millions of individual variants}} \rightarrow \boxed{\text{a structured mutation profile}} \)

Reverse-Complement Normalization

DNA is double-stranded. Suppose one strand contains \( C\rightarrow T \). The complementary strand contains \( G\rightarrow A \).

These are the same physical mutation viewed from opposite strands. To avoid double-counting, computational analyses often choose a canonical pyrimidine representation.

Thus, \( G>A \) is represented as its complementary \( C>T \).

This is a beautiful example of molecular structure directly influencing computational data representation.

Hidden Assumptions in a VCF

When we see REF=C, ALT=T, the pipeline has assumed that:

  1. reads were generated correctly
  2. base calls are sufficiently accurate
  3. sequencing errors are modeled
  4. reads were aligned correctly
  5. the evidence is not caused by mapping artifacts
  6. the allele is sufficiently supported
\( \boxed{ \text{A variant call is an inference,} \\ \text{not a direct observation of a mutation molecule.} } \)

Independent Molecules vs Reads

Suppose PCR creates 20 copies from one original molecule. We might observe 20 reads → T. It looks extremely convincing.

But those 20 reads may represent 1 original molecule, rather than 20 independent observations.

This is why sequencing pipelines care about:

  • molecular duplicates
  • unique molecular identifiers (UMIs)
  • library complexity
  • strand evidence and base quality
\( \boxed{\text{How much independent physical evidence supports this sequence state?}} \)

The Pipeline as a Chain of Filters

Every stage is a filter. If an upstream stage is wrong:

\( \boxed{ \text{downstream computation can be perfectly executed} \\ \text{and still produce the wrong biological conclusion} } \)

The complete bioinformatics mental model is:

Structure ↓ Chemistry ↓ Damage ↓ Repair ↓ Replication ↓ Mutation ↓ Measurement ↓ Statistics ↓ Variant ↓ Biological inference

That is why understanding the methyl group on thymine is not a small detail. It is an example of how molecular chemistry ultimately becomes computational data.
