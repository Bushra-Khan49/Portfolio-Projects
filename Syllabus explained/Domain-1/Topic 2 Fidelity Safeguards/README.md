# 🧬 Domain 1 · Topic 2 — Fidelity Safeguards

An interactive, scroll-driven 3D visualization exploring DNA error prevention, proofreading, mismatch repair, and their connections to Bioinformatics.

## 🌐 Live Demo

**[View Live Site →](https://bushra-khan49.github.io/Portfolio-Projects/Syllabus%20explained/Domain-1/Topic%202%20Fidelity%20Safeguards/index.html)**

---

## 📖 What's Covered

| Section | Topics |
|---------|--------|
| **Importance** | Why accurate replication matters to prevent catastrophic mutation accumulation |
| **Chemistry limitations** | Why hydrogen bonding alone only gives 1 error per 100-1000 bases |
| **Layer 1: Presynthetic** | Active-site geometry, induced fit, and preventing incorrect bonding |
| **Layer 2: Proofreading** | 3' &rarr; 5' exonuclease activity (the molecular backspace) |
| **Layer 3: Mismatch Repair**| Detecting distortions, identifying the new strand (methylation/nicks) |
| **Bioinformatics Connections**| How fidelity underpins variant calling accuracy and evolutionary models |

---

## 🛠️ Tech Stack

- **Three.js** — 3D animated DNA helix in the background
- **GSAP + ScrollTrigger** — Scroll-driven card animations
- **Vanilla HTML/CSS/JS** — No frameworks, fast and lightweight
