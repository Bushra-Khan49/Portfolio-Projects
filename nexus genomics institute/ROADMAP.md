# 🗺️ Nexus Genomics Institute: The Project Roadmap

This document outlines the development milestones and long-term features for the **Nexus Genomics Institute** digital ecosystem.

---

## 📅 Currently Implemented
- [x] **v1.0**: Next.js 15 App Router codebase architecture.
- [x] **v1.1**: Supabase Database schemas & initial tables.
- [x] **v1.2**: Supabase Auth gate & RLS rules.
- [x] **v1.3**: Advanced Admin Dashboard for content management.
- [x] **v1.4**: Applicant recruitment tracking system.
- [x] **v1.5**: Premium glassmorphism design system & responsive styling.

---

## 🚀 Short-Term Goals (Next 3–6 Months)
- [ ] **PubMed API Synchronization**: Automate publication updates for the PI bibliography page using their PubMed ID.
- [ ] **Interactive Gene Viewer**: A lightweight web-based protein/sequence visualization widget using WebGL or 3D library wrappers.
- [ ] **Admin Email Alerts**: Trigger serverless email notifications (e.g. via Resend or SendGrid) to the PI when new scholar applications are received.
- [ ] **Export Applications to PDF**: One-click summary exporter for application candidates, facilitating review meetings.

---

## 📡 Long-Term Vision
- [ ] **Federated Genomic Dataset Hub**: Secure repository interface allowing verified institutional collaborators to access raw sequencing output files.
- [ ] **Lab Resource Booking system**: Calendar scheduler permitting students to reserve access times for high-throughput sequencing hardware.
- [ ] **Scholars Blog & Forum**: A place to announce genomic breakthroughs, sequencing benchmarks, and computational methodologies.
