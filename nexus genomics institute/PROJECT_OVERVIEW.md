# 🧬 Project Overview: Nexus Genomics Institute

## 🔬 Website Name
**Nexus Genomics Institute (Digital Portal & Research Hub)**

## 🎯 Purpose
To provide a premium, modern, and highly interactive digital home for the **Nexus Genomics Institute**. The site serves as both a public-facing research and information hub and a private, secure administrative control suite (powered by Supabase) for the Principal Investigator (PI) to manage research outputs, laboratory goals, scholar listings, and applicant recruitment pipelines without requiring direct technical knowledge.

## 👥 Target Audience
1. **Academic Peer Reviewers & PIs**: To examine research publications, scientific goals, and experimental facilities.
2. **Prospective Scholars & Interns**: To explore the research culture, active projects, and submit formal applications.
3. **Internal Lab Members**: To schedule weekly meeting sessions, coordinate agendas, and track individual progress.
4. **Institutional Funders**: To review strategic objectives, facilities lists, and general academic progress.

## 🚀 Core Features
- **Supabase-Backed CMS**: High-performance relational database structures managing all dynamic elements (no local JSON file edits required).
- **Next.js 15 App Router & React 19**: Server-side rendering (SSR) for static research assets and client-side updates (hydration) for dynamic data.
- **Secure Admin Panel**: Secure email/password and session-based authentication gate powered by Supabase Auth and Row Level Security (RLS) policies.
- **Applicant Intake System**: A multi-step application pipeline where prospective candidates submit CV files to Supabase Storage and fill in application records securely.
- **Dynamic Meeting Calendar**: Interactive upcoming presentation timeline with historical session search.
- **Responsive Dark/Glassmorphism Theme**: Fully responsive dark-mode styling with subtle grid animations, neon cyan accents, and clear typography.

## 🛠️ Tech Stack Preference
- **Core Framework**: Next.js 15 (App Router)
- **Frontend State & Components**: React 19 & TypeScript
- **Styling & Theme**: Vanilla CSS Modules (High-contrast scientific color system)
- **Animations**: Framer Motion (Staggered card entrances, smooth layout transitions)
- **Icons**: Lucide React
- **Backend & Storage**: Supabase (Postgres Database, Auth, and Storage buckets)
